# Vajra Jwellz

A responsive starter storefront for Vajra Jwellz, a fashion jewellery brand.

## Preview locally
Open `index.html` in a browser. The site is a static HTML/CSS/JavaScript storefront and does not require a build step.

## Current features
- Responsive homepage and collection navigation
- Product grid with category filters, search, and sorting
- Shopping bag with quantity controls and browser-local persistence
- Demo checkout form with basic customer and address validation
- Accessible labels, keyboard-friendly controls, and mobile layouts

## Important before accepting real orders
This is a front-end prototype. Product listings are sample content and use externally hosted demo images. The checkout is not connected to a server, order database, email/SMS notifications, inventory, shipping provider, or payment gateway. Do not treat demo checkout submissions as real orders.

Next production steps:
1. Replace sample products, prices, and images with Vajra Jwellz inventory.
2. Connect a backend/database for products, customers, inventory, and orders.
3. Integrate a payment provider (for example, Razorpay) after confirming the payment options.
4. Add order notifications, shipping/tax rules, privacy/terms/returns pages, and an admin dashboard.
5. Configure a custom domain and HTTPS hosting (GitHub Pages can host this static prototype).
